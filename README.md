# Playhouse
This is a model of a little book nook that I made for a Smiski! Yay!

  I made it using Onshape, and it was my first time. I had a lot of fun learning about the different tools and playing around with what I could create. I found it difficult to make round parts with more complex details, especially when I was designing the hammock chair. When thinking about what to add, I took inspiration for the clock from one that I saw a couple weeks ago when I was at IKEA. I'm going to be printing out the whole assembly as well, and I'm looking forward to putting it together!

  I had a great time designing this room and I will definitely be using Onshape again in the future!
